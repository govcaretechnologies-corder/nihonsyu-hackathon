HOW IT WORKS

診断のしくみ

質問
必須6問 ＋ ランダム4問
必須：予算・甘辛・定番か挑戦か・温度・度数・有名か通好みか
ランダム：口当たり・香り・酸味・キレ／余韻・純米／吟醸・生酒／火入れ など10問から4問
→ 何度やっても質問が変わり、自分の好みが言葉になっていく
判定
いちばん一致した銘柄を「みくじ」に
各銘柄に16の属性を持たせ、回答との一致率で順位づけ。
同点が複数あればランダムに1本。
→ 知らなかった銘柄との「偶然の出会い」を演出
質問されたら：銘柄データは8銘柄（車多酒造・東酒造）。属性はすべて2〜3択の値で持っていて、単純な一致数で判定しています。
OPEN DATA

あなたのアプリにも、県のオープンデータを

使うまでの3ステップ
① カタログで探してCSVをダウンロード
今回は「発地別観光入り込み客数」「国籍別外国人宿泊客数」
② 必要な行だけ抜き出してJSONに
アプリのコードに直接書けば、サーバーもDBも不要
③ 出典を表示する
アプリ内に出典名とカタログへのリンクを載せる
「読みもの」を「自分ごと」に
ユーザーの回答と、データを結びつける
「首都圏から」と答えると
293.4万人
＝令和4年に首都圏から石川を訪れた人。
統計表のままでは読まれない数字も、「あなた」に向けると届く。
データの取り込みは、CSVから必要な値を手で転記しただけ。数値が年1回更新される程度なら、APIがなくても十分使える。
DATA TIPS

これから使う人へ：CSVのクセと対処法

01
見出しが
複数行
人が見る表の形のまま。1行目がタイトル、年は3行目…と読み飛ばしが必要。
02
構成比と実数が
交互の行
同じ項目で「%」の行と「人数」の行が上下に並ぶ。
03
単位が
データごとに違う
観光入込は「千人」、外国人宿泊は「人」。そのまま足すと桁がずれる。
04
項目の
開始年が違う
欧州・豪州はH19〜、長野・東北はH26〜。それ以前は「その他」に含まれる。
→ 注記まで読むと、グラフの「段差」の理由が分かる。年は和暦表記なので、比較するときは西暦に直すと扱いやすい。

LINE

LINE連携は、URL 2つで作れる

そのまま使えるコード
// ① 結果をLINEで送る（シェア）
https://social-plugins.line.me/lineit/share
  ?url=アプリのURL&text=送る文章

// ② 公式アカウントを案内（友だち追加）
https://lin.ee/xxxxxxx
API登録・審査・サーバー不要、0円。自分のアプリの拡散にも、行政や企業の公式アカウントとの連携にも使える。
使ってもらうための工夫
LINEを開く理由をつくる
「Keepメモに残せば酒屋さんで見せられる」「友だちに勧める」
本体の体験を邪魔しない
案内は保存・シェアのあとに1回だけ
PCとスマホで出し分け
スマホは友だち追加、PCはQRコード表示
実際の案内文：「このアプリは、石川県の日本酒ハッカソンから生まれました／ハッカソンの詳細は、石川県公式LINEで紹介中です！」 行政の公式アカウントと組むと、アプリに信頼感が生まれ、官民協働の入口にもなる。
UI / UX

触って気づく、工夫と弱点

工夫
・白×金×黒、明朝体で「地酒の品格」を表現
・1画面1問、選ぶだけ。文字入力なし
・マスコット「じざけまる」で親しみやすく
・結果は「マッチ度100%」と言い切る＝みくじの演出
・インストール不要、URLだけで動く
弱点・これから
・銘柄は2蔵・8本のみ（地図の3蔵は「近日追加」）
・味の3軸は2段階で、細かな違いは出ない
・瓶・蔵の写真はまだ仮置き
・日本語のみ（欧州客の多さを考えると多言語化したい）
・観光データは県単位で、市町ごとの数字ではない
弱点は会場からのアイデアを募るきっかけに。「どのデータがあれば市町別にできる？」など。
